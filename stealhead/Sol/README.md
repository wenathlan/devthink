# Stealhead Sol

Stealhead is the FPS world and game application of the DevThink family: matches, rounds, ranking ladders, weapons and world assets under one game shell. This Sol theme is its web surface — a Vite + React SPA whose home, match, ranking, weapons and world routes render from the same sqlite database that `schema.prisma` and `drizzle.config.ts` describe.

```bash
pnpm install
pnpm dev
```
