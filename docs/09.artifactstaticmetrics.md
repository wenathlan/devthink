## Design conclusion

The reviewed market frequently asks for broad tab, debugger, cookie, navigation and all-sites capabilities. Devthink will not inherit that permission surface. Its default package remains active-tab, storage and side-panel only; the user can grant a narrowly scoped HTTPS origin for a reviewed session.
