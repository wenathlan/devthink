pending publication · the hung model

A typed label becomes a live URL

In the panel, a label stays pending until the whole flow below completes. Subdomains hang from the bought apex with a wildcard record pointing to the same edge — the visitor resolves it with stock DNS, the vhost is picked by Host header.

01

Validate

Format, collision and policy checks run before anything is written. A label that fails never reaches the zone.

02

Write zone

The label joins devthink.pro as an RRset with the zone standard: TTL 3600, NS and SOA on 86400.

03

Persist

Zone, RRset, keys and audit log land in the single database, with the previous version kept for rollback.

04

Republish

The pipeline signs, bumps the serial and pushes the change — production zones are never hand-edited.

05

Serve

NOTIFY fires, secondaries transfer, and a healthcheck confirms the answer from the big public resolvers.
