# stealthhead — the dossier

The FPS game platform of the family: matches, ranking, weapons and the precompiled world.

## Identity

- Category: game (FPS).
- State: game in construction — the honest label the surface carries.

## Objective

Run the competitive FPS on the precompiled doctrine: the world, the shaders and the navigation answer from the database ahead of time, the physics stay deterministic, and the engine files import from cadria and debonair as libraries.

## Features

- Match platform: the match ladder with the deterministic house physics (no external engine).
- Ranking: elo and glicko seats.
- Weapons: the arsenal seats with the deterministic ballistics.
- The precompiled world: shaders, BVH and navigation grids compiled into the database ahead of time (the database acts as the virtual GPU and CPU).
- Engine imports: the 3D seats come from cadria, the audio seats from debonair — stealthhead owns no engine file it can import.

## Interactions

- The match surface: join, play, watch the ranking.
- The arsenal and the world surfaces.

## Doctrine

- The precompiled law: the world answers from the database, never compiled at play time on the visitor machine.
- The import law: no duplicate engine logic — cadria and debonair answer as libraries.
