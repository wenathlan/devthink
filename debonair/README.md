Audio and DAW. Isolated marketing app for the operating system. Houses the katexis engine at the root; imports gateway, AI and workflow from devthink and versawase from cadria. This folder receives the debonair application per the complete tree.

# Debonair Sol

Debonair is the audio workstation (DAW) of the DevThink family, running on the katexis engine. This Sol theme is the workstation's web surface — a Vite + React SPA whose library, generate, studio and settings routes drive tracks, clips, mixer strips and text-to-music render jobs stored in the same sqlite database that `schema.prisma` and `drizzle.config.ts` describe.

```bash
pnpm install
pnpm dev
```
