# The app dossiers

One dossier per official app of the family — the purpose, the features and the interactions, separated by category, read from the actual code of each app.

- [argan](./argan.md) — the DNS and gateway library: zones, DNSSEC and the multi-transport edge.
- [cadria](./cadria.md) — the video, image and 3D studio housing the versawase engine.
- [cobaia](./cobaia.md) — the public monetization surface: plans, support rails and honest ad slots.
- [debonair](./debonair.md) — the audio workstation (DAW) housing the katexis engine.
- [devthink](./devthink.md) — the operating system and superplatform: CLI, gateway, workbench, extension, library and MCP.
- [forge](./forge.md) — the deployable clone of execution only: runners, queues and run logs.
- [foundry](./foundry.md) — the complete deployable clone: pipelines, sandboxes, images and artifacts.
- [getry](./getry.md) — the AI gateway: five provider versions, 35 routes, the thinking ladder and key rotation.
- [saddle](./saddle.md) — the binary computing engine: ninety sandbox modalities, virtualization and portable runners.
- [stealthhead](./stealthhead.md) — the FPS game platform: matches, ranking, weapons, world and netcode.
- [vault](./vault.md) — the storage library: the self-hosted database, auth and object store.
