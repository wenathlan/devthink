# saddle — the dossier

The master virtualization engine of the family: the VM, the sandbox, the microVM, the runner and the virtual hardware — the engine every app rides.

## Identity

- Category: virtualization engine.
- The ninety modalities: from the first (the complete virtual machine) to the ninetieth, every one a real executable seat.
- Competitor space: the edge processing engines (the infrastructure the family owns).

## Objective

Execute every workload of the family on the house infrastructure — never the visitor machine: not the browser, not the GPU, not the CPU, not the local storage. The engine runs 24h on the internet edge.

## Features

- The ninety modalities across four lanes: vm (the machine seats), hardware (the virtual hardware presentation), runner (the program execution), sandbox (the isolation, ports, files, storage, network, delivery).
- Real executors on every seat: qemu argv builders, docker flag arrays, firecracker seats, the language runtimes (node, bun, deno, go, python), the wasm instantiation, the babel compilation bridge, the yaml interpreter, the virtual file system, the wire packet builders and the sigv4 signing chain.
- The visitor guard: the dispatch gate refuses any request that asks for a visitor scope before one instruction rides.
- The eleven-architecture standard: linux-x64, darwin-arm64, windows-x64, linux-arm64, darwin-x64, windows-arm64, linux-x64-musl, linux-riscv64, wasm32, darwin-arm64-v8, windows-x64-gnu.
- The OS host profiles catalog: linux, grapheneos, omarchy, maruos, vanillaos, v, windows, android.
- The container trio: max, balanced, lite — the exotic seat only saddle carries.
- The OS distribution flavor lanes: linux, omarchy, vanillaos, android flavors with the grapheneos, maruos, v and windows catalog lanes.
- The queue orchestration: express, normal, batch.
- The engine plans seam: plan limits (for example the storage quota) arrive from outside and scope one run only — the engines themselves are unlimited.

## Interactions

- The engine CLI with the family chat design beside the functional commands.
- The modalities endpoint the family surfaces consume.

## Doctrine

- The critical law: the engine never touches the person's machine.
- Saddle first, vault second: the storage engine leans on saddle when it needs edge processing.
