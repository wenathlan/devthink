## Admissões de fake/mock/deferido

- **Sandbox era 100% simulada no navegador**: "é um simulador de terminal determinístico, não uma VM" (saddle/sandbox.ts resolvido por alias, não pelo pacote npm); boot instantâneo com dmesg fabricado; `dispatch()` interpreta texto contra VFS em memória. O próprio assistente admite "the sandbox is a client-side simulation" na auditoria (wave 25 Out) — as ondas seguintes migram para server lane com fallback offline **declarado**, mas o simulador permanece como fallback.
- **Vault "ZERO integration"**: `@wenathlan/vault` nomeado no manifest mas **nunca importado** por nenhum código do devthink; o devthink usava IndexedDB do navegador (~15 chaves localStorage + `devthink.db`) **violando a própria doutrina escrita** ("a interface never writes in the browser"). A storage lane final (storagelane.ts) é um **contrato vault-shaped no devthink**, não o vault real importado.
- **Contas eram só locais**: "the account exists only in that one browser profile" (IndexedDB credentials); OAuth rows renderizadas disabled (sem client-id envs); o callback parava em "received" sem trocar token; **o app de callback `domain.bot.ouath.auth.app` está VAZIO (0% pronto — 139 dos 141 arquivos são metadados .mimosa)**. Corrigido nas rungs finais (accountlane + exchange), mas exige deploy com servidor.
- **O "2GB de quota" NÃO EXISTIA**: nenhuma constante em nenhum app; a UI mostrava `navigator.storage.estimate()` do navegador. Substituído por quota do plano (piso 900MB) na storage lane.
- **Sandbox modalidades contam mentindo**: registry = 24 modalidades, package.json `"modes": 30`, dono diz 40, docs prometem 50 — three-way mismatch admitido.
- **Fakes visuais removidos ao longo do caminho** (admitidos e purgados): pílulas de ferramentas falsas do chat (Search/Deep research/Files/Image — só Thinking mexia no prompt); Doo card com resposta semeada inventada, echo-send, toasts falsos, stats inventadas (35/60/24, "Lap 27 of 39", "Over 100,000 creators"); setTimeout/setInterval teatrais (debonairview render fake 1300ms→"48kHz WAV sent"; forgeview feed replay 950ms; foundryview create sandbox 900ms; boot sleep aleatório 28-62ms por linha de dmesg); dots decorativos; player do cadria "everything else a mock exactly as labeled"; Akash CMS "login is 100% fake" e Publish/Preview decorativos.

1. **Plataforma realmente funcional self-hosted**: no fim, o deploy público ainda é o GitHub Pages estático (`wenathlan.github.io/devthink`) — as lanes "reais" (sandbox/storage/contas/OAuth) só funcionam com o **servidor hono rodando** (localhost CLI pairing); não há deploy de produção com servidor, domínio próprio (devthink.pro/dev10.pro) nem Vercel/Netlify (creds de deploy nunca obtidas — as que existiam eram de OAuth app, 403/401).
