# Toolcatalog walkthrough

The toolcatalog namespaces its tools by domain — browser, workflow, memory and system — and every tool carries its json schema inputs, its version, its consent requirement and its risk class in its metadata. The walkthrough for a client: list the tools, read the consent metadata before calling (a tool that declares the approval requirement blocks until the human approval gate answers), call the read tools freely inside the session grants, propose a plan through the plan proposal tool with the full grammar, wait for the review gate tool to carry the human answer, and watch the progress events stream back through the subscription. The dry run mode executes without side effects, the idempotency keys deduplicate the retries, and the tool mocks let a client exercise the whole catalog without a browser.
