# DevThink 1.1.10 design references

The v1.1.10 interface is an original DevThink implementation. These public sources informed hierarchy and interaction principles only; no third-party source, branding asset or component implementation was copied.

| Source | Applied principle |
| --- | --- |
| [Rare UI](https://www.rareui.com/) | Sparse black canvas, restrained high-contrast material, rounded utility controls and a single expressive focal element. |
| [OpenCode TUI](https://opencode.ai/docs/tui/) | Command-first work, visible keyboard affordances, category context and a terminal input as the persistent operational surface. |
| [OpenCode intro](https://opencode.ai/docs/) | A user can begin by stating an intention and progressively configure provider capability when the work requires it. |

The supplied screenshots additionally established the desired contrast, headline scale, browser-tab rhythm and entry-to-workspace progression. DevThink keeps its canonical ANSI identity, local-first credential boundary, compact identifiers and route-addressable web workspace.
