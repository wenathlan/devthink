# devthink — the dossier

The supreme operating system envelope and the monorepo root: the suite of native pages that consumes every family engine as a library.

## Identity

- Category: OS envelope / monorepo.
- Competitor space: GitHub, GitLab (the workspace surface).

## Objective

Be the system the person lives in: an OS for every AI and its agents, where every family engine answers as a library, every app opens as a window or a fullscreen route, and nothing is simulated.

## Features

- The web OS shell: windows 11 chrome with the trylle.com refinement, titlebar law, navbar smart interactions (float, dock, release).
- Window manager: spawn fit, resize handles, zoom widget (the browser zoom stays locked), the renderparity law (the panel window and the standalone route answer one geometry).
- The page suite: about, audio, auth, calculator, chat, console, docs, explore, files, games, gateway, history, image, intro, onboarding, panel, plans, policy, projects, providers, settings.
- The agent swarm: one agent per tab, the kill switch always present, message-edit checkpoint merging, the fusion engine between tabs.
- Memory ladder with crypto shred; the label store owning every shell string (no hardcoded copy in components).
- Onboarding flow persisting through the database seam (never the visitor browser storage).
- The explorer, the calculator and the native utilities — all real, all consuming the DB via better-sqlite3.

## Interactions

- Double-click an icon in the panel: the app opens inside the system window.
- Type the app route directly: the app opens standalone fullscreen — one geometry, both doors.
- The gateway chat with the provider family (google, github, gitlab).

## Doctrine

- The family law: devthink imports argan, cadria, cobaia, debonair, forge, foundry, getry, saddle, stealthhead and vault as libraries — never repeats a sibling logic.
- Node is the maestro: every engine answers the orchestrator.
