# DevThink

**DevThink** is a provider-neutral AI development workbench with a terminal CLI, an embedded local gateway and a static web workbench. The public source lives in the [DevThink repository](https://github.com/wenathlan/devthink); **DevThink** remains the product name.

> **Security boundary.** DevThink uses official provider APIs and credentials supplied explicitly by the user. It does not capture browser cookies, store browser sessions, solve CAPTCHAs, automate browser authentication or bypass anti-bot controls.

## The consolidated documentation

The whole documentation corpus of the operation — every text read, every commit audited, every group's documents — is consolidated, deduplicated and hierarchized into five documents under [`docs/`](docs/):

| Document | Content |
| --- | --- |
| [`docs/lei.md`](docs/lei.md) | The complete law of the operation: every owner complaint registered in any text, commit or conversation turned into a binding directive, each rule listed once. |
| [`docs/operacao.md`](docs/operacao.md) | The consolidated operation state, the audited history and the execution fronts. |
| [`docs/apps.md`](docs/apps.md) | The complete dossier of the eleven applications of the superplatform and their engines. |
| [`docs/seguranca.md`](docs/seguranca.md) | The complete census of security errors and workflow failures with the per-front resolution map. |
| [`docs/checklist.md`](docs/checklist.md) | The whole operation as a hierarchical checklist: every mapped complaint turned into a real, verifiable action. |

This README is the entry point the build stages into the distribution envelope; the five documents above carry the whole corpus.
